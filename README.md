# AxionX

Manage the city on facts.
Not on reports and complaints.

Placeholder landing page for [axionx.sa](https://axionx.sa). Static [Astro](https://astro.build) site, deployed on Vercel from the `main` branch.

## Stack

- Astro 7 (static output), no CMS, no client framework
- Self-hosted fonts via the Astro Fonts API: Geist, Geist Mono, IBM Plex Sans Arabic (Arabic script only)
- `astro:assets` for the dashboard screenshot (AVIF + WebP, responsive `srcset`)
- `@astrojs/sitemap` with hreflang alternates

## Scripts

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # → dist/
npm run preview
npm run assets    # regenerate placeholder favicons / OG images / dashboard source
```

| `src/layouts/Base.astro` | `<head>`: OpenGraph, Twitter, canonical, hreflang, icons, JSON‑LD, fonts |
| `public/` | Favicons, `og/`, `site.webmanifest`, `robots.txt` |

## Localisation / RTL

Both locales render the same components. `/ar` sets `lang="ar" dir="rtl"`; layout uses logical properties only, so it mirrors automatically. Latin text (brand name, numerals) keeps Geist through `unicode-range`, Arabic script falls through to IBM Plex Sans Arabic. Tracking is disabled for Arabic.

## Liquid layout

`1rem` equals `16px` at the 1724px Figma frame and scales with the viewport (`html { font-size: clamp(12px, 100vw / 107.75, 22px) }`); every dimension is in `rem`. Tablet (≤1023px) and phone (≤767px) switch to their own base so the single‑column layout stays legible.

## Replacing placeholder assets

Everything in `public/` is a placeholder generated by `scripts/generate-assets.mjs`. Drop the real files in place, keeping the names:

- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` (180×180)
- `icons/icon-192.png`, `icons/icon-512.png`, `icons/icon-maskable-512.png`
- `og/og-en.jpg`, `og/og-ar.jpg` (1200×630)

The dashboard screenshot lives in `src/assets/dashboard.webp` (2000px wide source; the build derives all sizes).
